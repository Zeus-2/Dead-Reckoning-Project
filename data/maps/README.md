# Study-area road network

`study_area_roads.osm.pbf` is the road-network extract used by my map-assisted V2 reconstruction.

The code resolves this file relative to the repository root as:

`data/maps/study_area_roads.osm.pbf`

I do not need to type or hard-code an absolute Windows path.

Because the PBF is larger than GitHub's normal single-file limit, I track it with Git LFS.
