# Private repository notice

I use this repository as a restricted academic evidence and reproducibility archive for my MSc dissertation. It can contain raw vehicle telemetry, GPS ground truth, journey timestamps and approximate private home/work locations. In combination, these data can disclose routes, routines and driving behaviour.

The repository is therefore intended to remain private and access-controlled. The dissertation appendix can provide the repository link for authorised academic review, but the complete research dataset is not intended for unrestricted public redistribution.

If I later create a public release, I should remove raw telemetry, real private-location configuration, precise GPS ground truth and any derived output that could recover private locations.
